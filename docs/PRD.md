# 声迹 EchoTrace PRD

## 1. 产品基础信息

| 项目 | 内容 |
|---|---|
| 游戏名称 | 声迹 |
| 英文名 | EchoTrace |
| 产品形态 | 手机端竖屏 WebApp 小游戏 |
| 游戏类型 | 听觉记忆 + 听音辨物 + 场景还原闯关 |
| 核心 Slogan | 记住每一种厨具的声音，靠听觉还原完整厨房 |
| 目标平台 | 移动端浏览器，优先适配 390×844 / 430×932 竖屏视口 |

核心玩法一句话：

玩家先在 8 秒记忆阶段观察厨房场景，并记住每个厨具的专属声音；随后厨房画面消失，玩家在多音效交织环境下点击掉落厨具，最终按厨房场景还原准确度结算。

## 2. MVP 目标

MVP 先验证完整闭环是否好玩：

1. 首页选择难度并开始游戏
2. 记忆页展示厨房场景和物品声音
3. 挑战页通过听音点击掉落物
4. 结算页展示还原准确度和评级

当前优先实现：

- 首页
- 记忆页
- 听音挑战页
- 结算页

暂不优先：

- 账号系统
- 排行榜
- 复杂道具系统
- 多主题厨房
- 关卡编辑器

## 3. 游戏流程

固定线性流程：

```text
首页 -> 记忆阶段（8s）-> 听音挑战阶段 -> 结算阶段 -> 再来一局
```

流程规则：

- 首页选择难度后点击“开始挑战”
- 进入记忆页后强制倒计时 8 秒
- 倒计时结束后场景黑屏，进入挑战页
- 挑战页收集完本局所有目标物品后自动进入结算页
- 结算页支持重新挑战或再来一局

## 4. 页面需求

### 4.1 首页

目标：

让玩家明确游戏主题、选择难度并开始游戏。

页面元素：

- 厨房背景图
- 顶部音效开关
- 顶部设置按钮
- 游戏 Logo“声迹”
- 玩法文案：靠听觉还原整个厨房
- 难度选择卡片
- 开始挑战按钮
- 底部玩法提示

难度配置：

| 难度 | 物品数量 | 说明 |
|---|---:|---|
| 新手简单 | 6 | 适合首次体验 |
| 普通进阶 | 12 | 推荐多数玩家 |
| 困难硬核 | 18 | 高手挑战 |

交互规则：

- 默认选中新手简单
- 点击难度卡片切换当前难度
- 点击“开始挑战”进入记忆页
- 音效开关控制全局音效状态

### 4.2 记忆页

目标：

让玩家建立“物品外观 = 专属声音”的短时记忆。

页面元素：

- 顶部标题：记住每一件厨具的声音
- 8 秒倒计时
- 完整厨房场景
- 本局目标厨具标记
- 当前发声物品提示

规则：

- 记忆阶段固定 8 秒，不可调整
- 所有本局物品按固定顺序依次弹动
- 每个物品弹动时播放该物品专属单音效
- 记忆阶段单轨播放，不做混音
- 全部物品轮播完后，剩余时间保持画面静止
- 8 秒结束后停止单音效，进入黑屏过渡

### 4.3 听音挑战页

目标：

玩家在视觉屏蔽厨房场景的情况下，根据混音点击正确厨具。

页面元素：

- 深色或简约背景
- 顶部提示：听音辨物，还原厨房场景
- 随机掉落的厨具
- 底部收纳框
- 还原进度

音频规则：

- 进入挑战页后，本局目标物品音效同时循环播放
- 音效全程不中断
- 音效随着游戏过程不断叠加不同的音响，最初是一个音效，最多可以三个音效叠加
- 核心厨具音效音量保持统一

掉落规则：

- 掉落池为本局记忆阶段出现过的全部物品
- 物品随机横向坐标出现
- 物品匀速下落
- 屏幕内同时最多 5 个掉落物
- 

点击判定：
- 现在该点击什么物品根据当前的背景音乐进行判断。
- 点击正确物品：物品发光、飞入收纳框、计入正确数量
- 点击错误物品：物品爆炸或碎裂、消失、错误次数 +1
- 到达60秒后游戏停止，进入结算页。进入结算页之前保证所有待选择的物品用户都有机会被正确点击一次。
- 物品可重复被点击，如果正确了就在框里面显示一次，如果点击错误一次就直接从框里去掉

### 4.4 结算页

目标：

展示玩家本局厨房还原表现。

页面元素：

- 复原厨房场景
- 还原准确度百分比
- 答对数量
- 错误次数
- 通关用时
- 评级文案
- 重新挑战 / 再来一局按钮

评级规则：

| 准确度 | 评级 |
|---:|---|
| 90% - 100% | 顶级听音厨神 |
| 70% - 89% | 资深厨房大师 |
| 50% - 69% | 新手厨师学徒 |
| 50% 以下 | 听力有待提升 |

## 5. 计分规则

核心指标：

```text
还原准确度 = 正确收集物品数 ÷ 本局总物品数 × 100%
```

规则说明：

- 不做时间加分
- 不做速度加分
- 点错不扣除已正确数量
- 错误次数单独展示
- 最终比拼维度以还原准确度为主

## 6. 素材规范

### 6.1 场景图

首页背景图：

```text
frontend/public/scenes/home-background.png
```

记忆页完整厨房图：

```text
frontend/public/scenes/kitchen-memory.png
```

移除可交互物品后的厨房背景图：

```text
frontend/public/scenes/kitchen-empty.png
```

### 6.2 物品图标

路径：

```text
frontend/public/items/
```

要求：

- 每个物品一个透明 PNG
- 文件名使用英文小写、下划线或短横线
- 图标边缘干净，不带大块背景
- 坐标基于手机竖屏画布

### 6.3 点位配置

建议文件：

```text
frontend/public/scenes/kitchen-layout.json
```

推荐结构：

```json
{
  "scene": {
    "image": "/scenes/kitchen-empty.png",
    "memoryImage": "/scenes/kitchen-memory.png",
    "width": 390,
    "height": 844
  },
  "items": [
    {
      "id": "wok",
      "name": "炒锅",
      "icon": "/items/wok.png",
      "sound": "/sounds/kitchen-items/wok.mp3",
      "x": 190,
      "y": 430,
      "width": 72,
      "height": 72
    }
  ]
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| `id` | 物品唯一英文标识 |
| `name` | 中文展示名 |
| `icon` | 透明图标路径 |
| `sound` | 专属音效路径 |
| `x` / `y` | 物品中心点坐标 |
| `width` / `height` | 前端展示尺寸 |

### 6.4 音效

厨具音效路径：

```text
frontend/public/sounds/kitchen-items/
```

反馈音效建议路径：

```text
frontend/public/sounds/feedback/
├── correct.mp3
├── wrong.mp3
└── complete.mp3
```

要求：

- 单个厨具音效建议 2-4 秒
- 可循环播放
- 音色差异明显
- 避免过于细碎、难辨认的声音
- MVP 可以先使用 `.wav` 或 `.mp3`，后续统一格式

## 7. 技术实现约定

前端技术栈：

- Vue 3
- Vite
- TypeScript
- Pinia
- Vue Router

目录约定：

- 页面：`frontend/src/views/`
- 状态：`frontend/src/stores/`
- 类型：`frontend/src/types/`
- 组合函数：`frontend/src/composables/`
- 静态资源：`frontend/public/`

移动端适配：

- 默认竖屏设计
- 优先验证 390×844 和 430×932
- 桌面预览时以手机宽度居中显示
- 避免按钮文字溢出
- 关键操作区域适合手指点击
