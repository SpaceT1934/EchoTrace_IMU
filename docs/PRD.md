# 声迹 EchoTrace PRD

## 1. 产品基础信息

| 项目 | 内容 |
|---|---|
| 游戏名称 | 声迹 |
| 英文名 | EchoTrace |
| 产品形态 | 手机端竖屏 WebApp 小游戏 |
| 游戏类型 | 听觉记忆 + 听音辨物 + 陀螺仪体感交互 |
| 核心 Slogan | 记住每一种厨具的声音，靠耳朵和手还原完整厨房 |
| 目标平台 | 移动端浏览器，优先适配 390×844 / 430×932 竖屏视口 |

核心玩法一句话：

玩家先在 8 秒记忆阶段记住每个厨具的专属声音；随后挑战阶段通过陀螺仪倾斜手机控制底部收纳筐，接住发声的目标物品、避开干扰项，最终按准确度结算。

## 2. MVP 目标

MVP 验证完整闭环是否好玩：

1. 首页选择难度并开始游戏
2. 记忆页展示厨房场景和物品声音（8 秒）
3. 挑战页通过陀螺仪控制收纳筐接物品（60 秒）
4. 结算页展示准确度和评级、排行榜

全部已实现 ✅

## 3. 游戏流程

固定线性流程：

```text
首页 → 记忆阶段（8s）→ 听音挑战阶段（60s）→ 结算阶段 → 再来一局
```

流程规则：

- 首页选择难度后点击"开始挑战"
- 进入记忆页后强制倒计时 8 秒
- 倒计时结束后黑屏过渡，进入挑战页
- 挑战页 60 秒倒计时，结束后自动进入结算页
- 结算页支持重新挑战或再来一局

## 4. 页面需求

### 4.1 首页

页面元素：

- 厨房背景图
- 游戏 Logo"声迹"
- 玩法文案
- 三种难度选择卡片（新手 6 件 / 普通 12 件 / 困难 18 件）
- 开始挑战按钮
- 底部玩法提示

### 4.2 记忆页

目标：让玩家建立"物品外观 = 专属声音"的短时记忆。

规则：

- 记忆阶段固定 8 秒，不可调整
- 本局目标物品按固定顺序依次弹动
- 每个物品弹动时播放该物品专属单音效（纯单轨）
- 全部物品轮播完或 8 秒结束 → 黑屏过渡 → 挑战页

### 4.3 听音挑战页

**交互方式**：前置摄像头手势识别（实验后废弃）→ 改为陀螺仪倾斜手机控制底部收纳筐左右移动。手动触摸点击保留为备选。

**音效**：

| 阶段 | 时间 | 数量 |
|---|---|---|
| 阶段一 | 0-18s | 1 个声音 |
| 阶段二 | 18-38s | 2 个声音叠加 |
| 阶段三 | 38-60s | 3 个声音叠加 |

- 物品掉落速度平滑加速（间隔 900ms→260ms，速度 2.8s→1.1s）
- Web Audio API 截取循环播放，无缝切换

**掉落规则**：

- 声音响起 → 对应物品以 `isTarget=true` 掉落
- 干扰项由定时器随机混入（`isTarget=false`）
- 两大道严格单轨单物品，同一时间水平最多 2 个物品
- 物品出生即标定身份，终身不变

**碰撞判定**：

| 触发 | 标准 |
|---|---|
| 筐碰撞 | `isTarget` |
| 手动点击 | `activeIds` |

- 正确：物品发光 + 飞入收纳筐 + 去重
- 错误：爆炸粒子 + 屏幕震动 + 震动马达
- 点错已收集物品从筐里移除
- 60s 后游戏结束进入结算页

### 4.4 结算页

页面元素：

- 复原厨房场景
- 准确度百分比 + 答对数量 + 错误次数 + 得分
- 评级文案
- 排行榜：top 2 + 自己 + 超越百分比
- 名字输入框（随机生成名字）
- 重新挑战 / 再来一局按钮

评级规则：

| 准确度 | 评级 |
|---|---|
| 90%+ | 🏆 顶级听音厨神 |
| 75-89% | 🥇 资深厨房大师 |
| 50-74% | 🥈 新手厨师学徒 |
| <50% | 🌱 听力有待提升 |

## 5. 计分规则

```
得分 = 正确次数 × 10 + 已收集种类 × 准确率(%) × 0.1 - 错误次数 × 8
准确率 = 正确次数 ÷ (正确 + 错误) × 100%
```

## 6. 技术实现

### 前端

- Vue 3 + Vite + TypeScript
- Pinia 状态管理
- Vue Router SPA 路由
- DeviceOrientation API 陀螺仪
- Web Audio API 音效引擎

### 后端

- Node.js + Express + TypeScript
- SQLite（better-sqlite3）
- pm2 进程管理 + nginx 反代

### 部署

- HTTPS 自签名证书（端口 9090）
- Cloudflare Tunnel 作为移动流量备选（正规证书，微信可用）

## 8. 迭代记录

### 手势识别实验（已废弃）

曾尝试用 MediaPipe Hands + 前置摄像头实现手势交互。因以下原因废弃：
- WASM + 模型约 40MB，首次加载慢
- 摄像头 API 需要 HTTPS 安全上下文
- 光照和角度要求高，移动端体验不稳定

### 陀螺仪收纳筐（当前方案）

基于 DeviceOrientation API，通过 gamma 倾角控制筐位置：
- 不依赖摄像头，不需要额外权限（iOS 需点击确认一次）
- 零额外加载，响应延迟 < 50ms
- 两大道间隔宽，避免误碰
